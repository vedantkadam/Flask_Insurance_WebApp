How the prediction works

Customer & policy data

Age, income, policy type, tenure, risk score, insured value and claims history.

Feature processing

Numeric fields are scaled and categorical fields (policy type, segment) are one-hot encoded.

Linear regression model

A trained scikit-learn pipeline (model.pkl) combines the features into a single estimate.
